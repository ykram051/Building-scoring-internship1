# 🚀 Get Your FREE Google Gemini API Key

## Step-by-Step Guide

### 1. Go to Google AI Studio
Visit: [https://aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)

### 2. Sign In
- Use your Google account (Gmail, Google Workspace, etc.)
- No credit card required!

### 3. Create API Key
- Click "**Create API Key**" button
- Choose your Google Cloud project (or create a new one)
- Copy the generated API key

### 4. Add to Your App
Edit `app/.streamlit/secrets.toml`:
```toml
[gemini]
api_key = "your-copied-api-key-here"
```

### 5. Restart the App
- Stop the Streamlit application
- Start it again
- The chatbot will now have full AI capabilities!
